# AI 数据集标注与训练维护版 0.2.0：交付说明

## 运行方式

本次交付同时提供免安装版和安装版，两者功能相同，均与原软件独立。

1. 免安装版：进入 `AI-Biaozhu-0.2.0-Standalone`，双击 `AI-Biaozhu.exe`。
2. 安装版：运行 `AI-Biaozhu-Maintenance-Setup-0.2.0-x64.exe`，按安装向导操作。

不要只复制 `AI-Biaozhu.exe`；它必须与所在目录的 DLL、Python、Torch、Qt 等文件一起使用。

## 与原软件的关系

- 维护版使用独立版本号、应用名称、安装 AppId、默认安装目录、设置命名和用户数据目录。
- 原软件不会被覆盖，两个版本可以并存。
- 构建及安装烟测前后，原版两个 EXE 和原版快捷方式哈希均保持不变。

## 本版主要维护内容

- 混合导入 MaixHub/VOC 的已标注、空标注和未标注图片。
- AI 重框去重、历史草稿清理、重框与贴边质量提醒。
- 标注显示模式、框拖动/缩放锁定、重叠框循环选择、类别显示别名。
- 多选、全选、范围选择和训练样本集合；训练前预检与不可变快照。
- 可配置早停、训练结束原因、损失曲线与 mAP 曲线分图显示。
- Docker 大镜像导入进度、心跳、取消、停滞诊断和重启恢复。
- MaixCAM-Pro / MaixCAM2 参数隔离、校准图片快照校验。
- 可同时生成 `.maixapp` 和可编辑 MaixVision 工程，并明确区分“生成”与“安装到设备”。
- 真机验证后可通过二次确认永久清理旧备份。
