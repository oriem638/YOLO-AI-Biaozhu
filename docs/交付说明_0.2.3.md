# AI 数据集标注与训练维护版 0.2.3：小更新说明

## 本次解决的问题

维护版 0.2.3 针对“误建了一个没有任何标注框的类别，训练前检查因此提示该类别没有实例并阻止训练”的情况，增加安全、可恢复的处理入口。

- 在“标注”页的类别区域增加“删除空类别”按钮。
- 训练前检查发现零实例类别时，给出明确操作指引：若该类别确为误建且整个项目中没有标注框，可返回“标注”页选中它并删除；处理后重新执行训练前检查。
- 删除前检查的是整个项目，而不只是本次参与训练的图片。只有全项目标注框数量为 0 的类别才允许删除。
- 若该类别在未确认图片、未加入训练的图片或其他任意图片中仍有标注框，软件会拒绝删除并显示实际框数，避免误删有效类别及标注。
- 项目必须至少保留一个类别；软件拒绝删除最后一个类别。
- 每次成功删除空类别前自动备份项目数据库，并在界面提示备份位置。
- 删除空类别只移除该类别及其兼容别名，不修改其他类别、图片、标注框、确认状态、训练成员、历史模型和部署产物。

## 针对当前项目的操作

当前项目中真实标注均属于 `BALL`，误建类别“钢球”没有任何实例时，可按以下步骤处理：

1. 打开“标注”页。
2. 在类别列表中选中“钢球”。
3. 点击“删除空类别”。
4. 阅读影响范围和备份提示后确认。
5. 切换到“训练”页，重新点击“一键训练”执行训练前检查。

若软件提示该类别仍有标注框，则不要强行删除。应先定位这些图片，确认框属于错误类别后再人工改类或删除；软件不会把“本次训练中为 0 个实例”误当成“全项目为空”。
