# AI 数据集标注与训练维护版 0.2.1：热修复交付说明

## 修复内容

`0.2.1` 修复了 `0.2.0` 在空项目中导入 MaixHub/Pascal VOC 数据时静默退出的
问题。空项目没有当前图片时，软件现在会跳过无意义的保存动作，继续执行预检和
正式导入。

导入期间界面会依次显示：

1. `正在检查 VOC 数据集…`
2. `正在重新预检 N 张图片…`（合并模式）
3. `正在导入 N 张 VOC 图片，请勿关闭软件…`

处理期间导入按钮和菜单入口会临时禁用，完成或失败后自动恢复。关键阶段同时写入
维护版应用日志。

## 升级关系

- `0.2.1` 使用与维护版 `0.2.0` 相同的 AppId、安装目录、快捷方式和用户数据身份，
  安装时会直接覆盖升级 `0.2.0`。
- 最初的原软件使用不同 AppId 和数据身份，不会被覆盖。
- 项目数据库不会因软件升级而删除，但同一项目不要同时由两个程序实例编辑。

## 验收重点

- 新建一个 `0/0` 空项目，然后把真实 VOC 数据选择“合并到当前项目”。
- 确认开始后应看到阶段提示，约十几秒后出现完成报告。
- 本次真实样本基准为：1062 张图片、796 个框、796 张已确认、266 张未确认。
- 验证结束后检查原软件仍可启动，原项目和模型文件保持不变。
