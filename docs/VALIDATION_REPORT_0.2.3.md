## 功能验收范围

### 安全删除空类别

- 类别在整个项目中的标注框数量为 0 时，可从类别区域删除。
- 成功删除前自动创建数据库备份。
- 删除后其他类别、图片、标注框、训练成员及项目统计保持不变。
- 训练前检查重新执行后，不再因已删除的误建空类别阻止训练。

### 数据保护门禁

- 类别只要在全项目任意图片中存在标注框，即使本次训练子集中实例数为 0，也必须拒绝删除。
- 拒绝提示包含该类别在全项目中的实际标注框数量。
- 项目只剩一个类别时，必须拒绝删除最后一个类别。
- 用户取消确认时，不创建删除结果，不改变类别和项目数据。

### 训练前引导

- 训练前检查继续拒绝启用但零训练实例的类别，不自动忽略类别，也不自动删除数据。
- 错误提示说明安全处理路径：返回“标注”页，选中误建类别，点击“删除空类别”，再重新执行训练前检查。
- 若类别并非全项目为空，删除入口会再次执行全局检查并拒绝操作。
