# Bundled CJK font

`NotoSansSC[wght].ttf` is bundled so the Chinese interface remains readable
on Windows installations without a CJK system font. The application loads it
at startup and still falls back to installed Windows fonts if loading fails.

- Official source: <https://github.com/google/fonts/blob/main/ofl/notosanssc/NotoSansSC%5Bwght%5D.ttf>
- License: SIL Open Font License 1.1, available at
  <https://github.com/google/fonts/blob/main/ofl/notosanssc/OFL.txt>
- Vendored font SHA-256:
  `763146584cf0710223441356b4395e279021b0806c196614377a7a0174ae074a`
- Embedded family/version: `Noto Sans SC`, `Version 2.04`

The adjacent `OFL.txt` must remain beside the font in source archives,
standalone builds, and installers.
